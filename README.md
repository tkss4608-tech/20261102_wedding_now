# 모바일 청첩장 웹사이트

## 레이아웃\nPC와 모바일 모두 한 페이지 안에서 위에서 아래로 이어지는 세로 스크롤 방식입니다. 데스크톱에서는 콘텐츠가 중앙의 읽기 편한 폭으로 표시됩니다.\n\n## 실행 방법
1. 압축을 푼 뒤 `index.html` 파일을 브라우저에서 엽니다.
2. 웹에 공개할 때는 폴더 전체를 정적 호스팅 서비스(Netlify, GitHub Pages 등)에 업로드합니다.
3. `assets` 폴더를 포함해 폴더 구조를 그대로 유지해야 이미지가 정상 표시됩니다.

## 수정할 내용
- 신랑·신부 이름, 예식 날짜와 시간: `index.html`에서 검색해 수정
- 예식장 이름·주소: `index.html`의 `info-list`, `address` 부분 수정
- 구글 지도 목적지: `index.html`에서 `google.com/maps/search`로 검색해 URL의 장소명 변경
- 계좌번호: `data-copy` 값과 화면에 보이는 은행·계좌 텍스트를 함께 변경
- 사진: `assets` 폴더의 JPG를 교체하거나 파일명을 유지한 채 본인 웨딩 사진으로 덮어쓰기

## 파일 구성
- `index.html` : 페이지 구조와 콘텐츠
- `css/style.css` : 디자인, 반응형 레이아웃
- `js/script.js` : 사진 팝업과 계좌번호 복사 기능
- `assets/` : 웹사이트에 실제로 포함된 사진 파일

## 참고
현재 이름, 날짜, 장소, 계좌번호는 예시입니다. 실제 배포 전에 반드시 본인 정보로 변경하세요.
지도는 Google Maps 검색 링크를 사용하며, 지도 미리보기는 외부 이미지 링크가 아닌 CSS로 만든 간단한 안내 그래픽입니다.
